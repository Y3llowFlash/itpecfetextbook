# Owner-provided landing reference and original covers

These are the seven original PNG attachments supplied by the owner in this conversation, saved without pixel changes. They are design resources, outside the public asset tree. The reference guides the composition; it is never displayed as the page itself.

Landing selections: `fe-vol-1.png`, `ip-main-2017.png` (main 2017 edition, not the supplement), `ap-vol-1.png`. The unused FE Volume 2, IP syllabus supplement and AP Volume 2 remain here for future development.

Run `npm.cmd run prepare:covers` to regenerate the six lossless responsive WebPs and `src/content/book-covers.json`. Native-size decoded pixels must equal the supplied originals. The application exposes only those six approved derivatives, never this directory or the reference screenshot.
